# プロジェクトマネジメント 02 EVM（出来高管理）

過去問の本文は載せない。公式と、読み方・解き方だけを書く。

---

## 1. 3つの基本値

| 記号 | 名称 | 意味 |
|---|---|---|
| PV | Planned Value（計画価値） | 現時点までに完了している予定だった作業の予算 |
| EV | Earned Value（出来高） | 現時点までに実際に完了した作業の予算（予算で評価） |
| AC | Actual Cost（実コスト） | 現時点までに実際にかかった費用 |
| BAC | Budget At Completion | 完成時総予算（計画の総額） |

- 重要: EVは「実際にかけた金額」ではなく、「完了した作業を、当初予算で換算した金額」。
- 例: 総予算1,000万円、進捗40%なら、EV＝400万円。ACが500万円でもEVは400万円。

---

## 2. 差異と効率

| 指標 | 式 | 読み方 |
|---|---|---|
| CV（コスト差異） | EV − AC | 負ならコスト超過 |
| SV（スケジュール差異） | EV − PV | 負なら遅れ |
| CPI（コスト効率指数） | EV ÷ AC | 1未満なら超過 |
| SPI（スケジュール効率指数） | EV ÷ PV | 1未満なら遅れ |

- 覚え方: どれも EV が主役。差異は引き算、指数は割り算。
- 引き算の順序は常に「EV − ○○」。

---

## 3. 完成時の予測（EAC・ETC・VAC）

| 指標 | 式 | 使う場面 |
|---|---|---|
| EAC（完成時総コスト予測）A | BAC ÷ CPI | 今のコスト効率が、最後まで続くと見る |
| EAC B | AC + (BAC − EV) | 超過分は取り戻せないが、残りは計画どおりと見る |
| EAC C | AC + (BAC − EV) ÷ (CPI × SPI) | コストと進捗の両方が、残りに影響すると見る |
| ETC（残作業コスト予測） | EAC − AC | |
| VAC（完成時差異） | BAC − EAC | 負なら超過見込み |
| TCPI（完成までの残コスト効率） | (BAC − EV) ÷ (BAC − AC) | 予算内に収めるために必要な効率 |

- IPA講評（令元秋 問9 設問2(3)、低い）: 与えられたEVM指標値を使って、将来の予測を立てる方法を身に付ける。
- 設問は、どの前提で予測するかを必ず指定している。「今後も同じ効率」なら A、「今後は計画どおり」なら B。
- 前提の文言の例: 「今後は計画どおりに進む」→B／「現在の効率が続く」→A。

---

## 4. 解き方の手順

1. 本文から PV・EV・AC・BAC を表に抜き出す
2. EV は、完了した作業の予算を足す（進捗率×予算でもよい）
3. 設問が聞いている指標の式を書く
4. 単位（万円、人月、人日）をそろえる
5. 「何を予測するか」の前提を確認してから、EACの式を選ぶ

---

## 5. 良くある誤り

- EV と AC を取り違える（EVは完了した作業の「予算」）
- 差異の引き算の向きを逆にする
- 指数を「悪いほど大きい」と考える（1未満が悪い）
- EACの前提を読まずに BAC÷CPI を使う

---

## 6. 記録しておく問い（自分の確認用）

- SPI < 1 なら、必ず「予算超過」か？ → 違う。SPIは進捗、CPIはコスト。
- CPI > 1 かつ SPI < 1 は、どういう状況か？ → 予算内だが遅れている。
