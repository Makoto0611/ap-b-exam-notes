# ap-b-exam-notes

応用情報技術者試験（科目B）の学習ノート。手を動かして覚える教材と、解き方のメモをまとめている。

日々の学習ログ・スケジュールは別の場所（work-diary）で管理し、ここは「具体的な知識を調べるときの参照先」として使う。

## 中身
| フォルダ | 内容 |
| --- | --- |
| `sql-handson/` | 問6（データベース）のSQL・E-R図の練習キット。`sql.py` で実行して確認できる |
| `kamoku-b/` | 科目Bの解き方メモ（空欄の埋め方、弱点メモ） |

## はじめに見るもの
1. 空欄に何を書くか分からない → `kamoku-b/blank-filling-method.md`
2. SQLの構文や、本文の言葉との対応を調べたい → `sql-handson/cheatsheet.md`、`sql-handson/04_condition_to_sql.md`
3. 毎日10分の練習をしたい → `sql-handson/02_exercises.md`
4. E-R図・正規化・トランザクション → `sql-handson/05_design_basics.md`

## 方針
- 過去問の問題文・図表は載せない（著作権のため）。「どの空欄で何を見るか」という考え方だけを書く
- 例題とサンプルデータは、型を再現した自作のもの
- Python 3 の標準ライブラリだけで動く（インストール不要）
